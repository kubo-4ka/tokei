# シンプル時計

画面いっぱいに時刻を表示して、ずっと置いておくための静的 Web アプリです。
色・フォント・大きさ・地域（タイムゾーン）・曜日・日本語／英語・秒やミリ秒などを細かく変えられますが、ふだんは時計だけが表示されます。

HTML / CSS / JavaScript だけで動き、ホーム画面に追加（インストール）できます。オフラインでも動きます。

# DEMO

https://kubo-4ka.github.io/tokei/

## 使い方

- 画面を触る（マウスを動かす）と右上に **全画面** と **設定** のボタンが出ます。数秒で消え、マウスカーソルも隠れます
- キーボード：`S` 設定、`F` 全画面、`Esc` 設定を閉じる。ダブルクリックでも全画面
- 設定はその場で時計に反映され、この端末のブラウザ（localStorage の `tokei.settings`）に保存されます
- パソコンでは設定が右側に、スマホでは下からせり上がる形で開き、時計は残りの場所に縮んで表示されるので、見ながら調整できます

## 設定できること

| 分類           | 内容                                                                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 色             | プリセット 9 種（ナイト・ペーパー・スカーレット・バイオレット・ターミナル・アンバー・オーシャン・さくら・スター）、背景・時刻・日付の色、単色／グラデーション（向き）、文字を光らせる |
| 時刻           | 24 時間／12 時間、午前・午後（AM・PM）、時を 2 けたにする、区切り（`12:34` / `12.34` / `12時34分`）、区切りの点滅、秒、ミリ秒（なし／1〜3 けた）、秒・ミリ秒を小さく                  |
| 日付・曜日     | 表示の有無、形式（年月日／月日／和暦／`2026/10/15`／`2026-10-15`）、曜日（なし／短く／長く）、漢数字（十月十五日）、土曜を青・日曜を赤、時刻の上か下か、大きさ                        |
| 言語・地域     | 日本語（漢字）／English、地域（主な都市 48 か所＋ブラウザが知っている全タイムゾーン）、地域名・UTC との時差の表示、ほかの地域の時刻（4 つまで。日付がずれると「翌日／前日」）         |
| 文字           | フォント 9 種（すっきり・まるい・ゴシック・明朝・等幅・デジタル・ドット・クラシック・端末の標準）、太さ、時刻の大きさ（画面の幅に対して）、縦・横の位置                               |
| ずっと表示する | 画面を消さない（Screen Wake Lock API）、焼き付き防止（1 分ごとに少しずらす）、明るさ、夜は暗くする（時刻の範囲と明るさ）                                                              |

時刻の大きさは、数字をすべて `0` にした「型」の幅をはかって、画面の幅と高さに収まるように自動で決めています（等幅数字なので、時刻が変わっても大きさや位置が揺れません）。

12 時間表示は、日本語では「午後 0 時」、英語では「12 PM」の書き方です。

## 注意

- 「画面を消さない」は対応ブラウザ（Chrome・Edge・Safari 16.4 以降など）で、https か localhost のときだけ効きます。省電力モードなどで解除されることがあり、そのときは画面を触ると再度試します。効かない環境では端末の自動ロックの設定で調整してください
- iPhone の Safari は全画面ボタンに対応していないため、ボタンは出ません。ホーム画面に追加すると、アドレスバーなしで表示できます
- 「夜は暗くする」はこの端末の時刻で判定します（表示している地域の時刻ではありません）
- フォントは Google Fonts から読み込みます。設定の画面を開いたときだけ、見本用にすべてのフォントを読み込みます

## ファイル構成

| ファイル                                                    | 内容                                                                                            |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `index.html`                                                | 画面                                                                                            |
| `style.css`                                                 | デザイン。時計の色と大きさは app.js が CSS 変数（`--bg1` `--bg2` `--fg` `--sub` `--t`）に入れる |
| `app.js`                                                    | アプリ本体（時刻の組み立て・大きさ合わせ・設定の画面・画面を消さない・焼き付き防止）            |
| `manifest.webmanifest` / `sw.js` / `icons/` / `favicon.svg` | インストール用の設定・オフライン用キャッシュ・アイコン                                          |
| `tools/serve.js`                                            | ローカル確認用サーバ（`node tools/serve.js` → http://localhost:26842/ 、`--https` で HTTPS）    |
| `tools/make-cert.js`                                        | iPhone などで確認するための自己署名証明書を作る                                                 |
| `tools/make-icons.js`                                       | `icons/` の PNG を作り直す                                                                      |

ファイルを変えたら `sw.js` の `VERSION` を上げてください（インストール済みのアプリが更新を受け取るため）。

### 設定の画面に項目を足すとき

`app.js` の `DEFAULTS` に初期値を、`UI()` に項目を足します。

```js
{ k: 'seconds', type: 'toggle', label: '秒を表示' },
{ k: 'ms', type: 'seg', label: 'ミリ秒', opts: [[0, 'なし'], [1, '.1']], show: () => S.seconds },
```

`type` は `seg`（ボタンで選ぶ）／`toggle`／`range`／`select`、`show` が false を返すと隠れます。保存した設定は `DEFAULTS` と型が同じものだけ読み込むので、項目を足しても古い保存データで壊れません。
